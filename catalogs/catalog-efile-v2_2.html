990 Efile Data Catalog

Archived interim release · efile_v2_2

Superseded. This page lists efile_v2_2, an interim build that was not a full public release. It is kept so that analyses run on it can be reproduced. The current 990 / 990-EZ release is efile_v3_1.

This build adds about 500,000 late-arriving filings for tax years 2022–2024 and introduces tax year 2024. It is purely additive: no previously published filings were revised. Details are in the release note; all data releases are listed on the data release notes page.

Release efile_v2_2 (published 2026-08-11)
Returns Form 990 and Form 990-EZ, with schedules
Tax years 2009–2024
Tables 111 tables, 1,698 table-year files
Filings 5,675,704 returns

Each table-year is published as CSV and Parquet. Data dictionary links point to the current concordance990 dictionary, so a few variables may differ from the ones in this release.

Anchor your code to a release. panelize() reads the current release (efile_version()) unless told otherwise, so the same code returns different data after the next release. For reproducible results, name the release explicitly:

panel <- 
  panelize( tables = "F9-P01-T00-SUMMARY",
            years = 2020:2024,
            source = data_source( version = "v2_2" ),
            bmf = TRUE )

BMF fields come from the current NCCS master BMF. To fix those as well, save the BMF once and pass the data frame or file path to bmf =.
