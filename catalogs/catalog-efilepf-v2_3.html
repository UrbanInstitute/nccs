Superseded. This page lists efilepf_v2_3, an interim build that was not a full public release. It is kept so that analyses run on it can be reproduced. The current 990-PF release is efilepf_v3_1.
Release efilepf_v2_3 (published 2026-10-07)
Returns Form 990-PF
Tax years 2009–2024
Tables 81 tables, 1,288 table-year files
Filings 1,151,314 returns

Each table-year is published as CSV and Parquet. Data dictionary links point to the current concordance990 dictionary, so a few variables may differ from the ones in this release.

Anchor your code to a release. panelize() reads the current release (efile_version()) unless told otherwise, so the same code returns different data after the next release. For reproducible results, name the release explicitly:

panel <- 
  panelize( tables = "PF-P01-T00-REVENUE-EXPENSE",
            years = 2020:2024,
            source = data_source( version = "v2_3", form = "990PF" ),
            bmf = TRUE )

BMF fields come from the current NCCS master BMF. To fix those as well, save the BMF once and pass the data frame or file path to bmf =.
